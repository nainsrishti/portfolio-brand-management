## Flags — tighten these yourself before publishing

1. **FinFloww "1M+ reach, 22K likes" and the "More of What I Do" "finance threads with 1M+ reach"** — these read as possibly the same stat, told twice, or possibly two different things (one post vs. multiple threads). If it's one post, say so once and reference it in both places consistently. If it's a separate thread, give it its own number instead of reusing "1M+."

2. **"22K to 25K members, 9K to 15K LinkedIn" (More of What I Do) vs. "9K to 15K LinkedIn, 400+ new members" (IMTAA card)** — the LinkedIn number matches, but "22K to 25K members" doesn't appear anywhere else and it's unclear which org, platform, or time period it refers to. A brand manager reviewer will ask "22K to 25K of what, exactly, and when?"

3. **"30,000+ MBAs, CEOs, CXOs, and founders"** — worth a source or footnote (registered alumni database count vs. estimate) since it's the credibility anchor for the whole IMTAA case study.

4. **"400+ new members"** — no timeframe attached. Over what period?

5. **"Built IMTAA's Angel Network from zero"** — no outcome metric (number of investors onboarded, deals facilitated, capital connected). If you have one, it would strengthen this into a real case study rather than a description of scope.

6. **"Women in AI"** — unclear whether you organized/owned this event or attended/spoke at it. Ownership matters for a brand manager narrative ("I built this" vs. "I was part of this").

7. **`pdabout.md`** — this file in your folder has an entirely different, older bio (product-design framing, not community/brand) and isn't linked from any page. It looks like a leftover draft. Worth deleting or ignoring so it doesn't confuse anyone editing the site later.
